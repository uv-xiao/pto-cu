# Persistent Smoke Fallback PTX Resources

## Scope

Move generated fallback PTX out of
`.agents/skills/cuda-backend-eval/scripts/cuda_persistent_smoke.py` without
changing the persistent smoke runner's CLI, exported helper behavior, or
`embedded-sm80-*` report labels.

## Result

- Added a small `cuda_persistent_smoke_impl` helper package.
- Added separate PTX resource files for the direct vector-add, queue
  vector-add, and DAG fallback executors.
- Updated the runner to import fallback bytes from the helper package.
- Verified the resource PTX bodies match the previous embedded literals except
  for trailing blank EOF normalization.
