# CUDA Capture Validator Preset Split

## Scope

Move the large paper-ready preset tables out of
`.agents/skills/cuda-backend-eval/scripts/cuda_validate_capture.py` without
changing validator CLI flags, preset names, or validation behavior.

## Result

- Added a small `cuda_validate_capture_impl` helper package.
- Added `presets.py` for paired-current and compact-current validation data.
- Updated the capture validator to import preset data from the helper module.
